# The Valley

Simulación idle de una aldea medieval para móvil. Una aldea que vive sola
durante siglos, y tú eres el poder que decide su destino en un puñado de
encrucijadas.

- **Diseño:** `docs/design.md` — especificación completa y briefs por módulo.
- **Para agentes:** `CLAUDE.md`.

```bash
npm install
npm run dev
```
