# P5 · Contrato de clips exportados y procedurales

Fecha: 17 de septiembre de 2026

## Reproducción

Antes del cambio, `npx vitest run tests/fast/graphics-clock.test.ts` fallaba:
la igualdad de cardinalidad exigía 12 entradas de `VILLAGER_CLIPS` y 4 clips
del GLB. El diagnóstico era correcto: `Cast` concatena los clips exportados con
`actionClips(idle)`, que genera las otras ocho acciones en runtime.

## Propiedades protegidas

La prueba del reloj conserva la verificación literal de cada clip declarado en
`art/catalog.json`: duración, bucle y zancada de `idle`, `walk`, `work_hoe` y
`carry_walk` siguen iguales a la tabla runtime.

La nueva prueba carga `villager.glb` mediante el cargador real y comprueba que:

- cada nombre de `VILLAGER_CLIPS` tiene un clip exportado o una acción que
  `actionClips(idle)` generó de verdad;
- un nombre sin respaldo resulta no respaldado;
- las ocho acciones generadas tienen nombres únicos, duración positiva y tiempos
  y valores finitos;
- las pistas apuntan a huesos que existen en el rig importado;
- serializar `idle` antes y después produce el mismo resultado.

No se cambió producción, catálogo ni recursos.

## Verificación

- Reproducción previa: `graphics-clock.test.ts`, exit code 1; `12` frente a `4`.
- `npx vitest run tests/fast/graphics-clock.test.ts tests/fast/procedural-clips.test.ts`:
  exit code 0; 11 pruebas correctas.
- `npm run typecheck`: exit code 0.
- `npm run lint`: exit code 0.

## Límite

El contrato prueba el villager publicado y la conexión actual de `Cast`; no
certifica naturalidad visual ni añade acciones, huesos o recursos nuevos.
