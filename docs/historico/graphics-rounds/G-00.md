## Inspección visual

La imagen muestra una base rectangular en perspectiva ortográfica y tres ejes
asimétricos: rojo hacia la esquina inferior derecha, amarillo hacia la superior
derecha y azul vertical, además de una esfera azul desplazada a la izquierda.
La silueta permite detectar inversiones y dobles rotaciones. Las sombras de los
brazos y de la esfera se leen bien. El primer intento salió enteramente blanco:
`diffuse_color` no bastaba para el material renderizado; se corrigió creando
materiales con nodos Principled, color base y rugosidad explícitos.

Defectos aceptables para esta prueba: las flechas son bloques con conos y no arte
de juego; el brazo amarillo queda parcialmente oculto por la cámara; no hay texto
de ejes. Son útiles para verificar coordenadas, no fijan el estilo visual.

## Circuito remoto y reanudación

El camino local demostrado es `doctor → Blender background → blend/GLB/PNG →
inspección de imagen → informe`. El host debe estar encendido y la tarea debe
poder ejecutar procesos; si Windows está suspendido, la ejecución no continúa.
Cada invocación reemplaza únicamente los cinco resultados conocidos de G-00,
mantiene un JSON final y un log, y puede retomarse ejecutando el mismo comando.

La carpeta `artifacts/` está ignorada por Git, por lo que no constituye por sí
sola un canal remoto. Esta conversación permite presentar el PNG, pero el estado
`probado desde fuera del host` exige abrir esta misma evidencia desde el móvil u
otro equipo. No se han abierto puertos, publicado archivos ni creado servicios.

## Hallazgos para arbitraje

1. **Ratificar:** Blender por scripts en segundo plano es viable en este host.
2. **Promover:** el éxito de Blender debe exigir artefactos y una marca explícita,
   no solo código de salida 0.
3. **Ratificar:** Playwright puede reutilizar Chrome del sistema; el Chromium
   empaquetado ausente no bloquea G-01.
4. **Mantener pendiente:** P0 necesita carga real del GLB en Three.js y prueba
   del canal desde un segundo dispositivo. La cabecera glTF no sustituye esa carga.
5. **Siguiente acción:** G-01 debe crear el visor mínimo y capturar este mismo
   recurso desde Three.js antes de iniciar arte complejo.

La hipótesis de automatización local no fue falsada. La hipótesis de operación
remota completa aún no puede ratificarse porque falta la comprobación externa.
