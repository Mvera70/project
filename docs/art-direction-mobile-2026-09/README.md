# Dirección de arte móvil — septiembre de 2026

Carpeta de trabajo para capturas, referencias y láminas generadas que apoyan el rediseño visual de Valley.

## Estructura

- `source-captures/`: copias de las tres referencias de partida; no se editan.
- `generated/`: imágenes nuevas producidas para evaluar dirección, composición, props o arte narrativo.
- `valley-rest-direction-api.json`: workflow reproducible de Qwen Image 2.1 local.

## Primera dirección

**Diorama vivo + libro de crónica**: el valle ocupa la mayor parte de una pantalla móvil; los controles y las decisiones se sienten como piezas físicas sobrias, no como un dashboard web. Esta lámina no es una pantalla para implementar píxel a píxel: fija luz, profundidad, escala, materiales y jerarquía.

## Fuente
