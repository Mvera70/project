# Pruebas tempranas de recursos visuales

Estas imágenes son pruebas exploratorias generadas antes de la tanda final de
ilustraciones de las crónicas. Se conservan como referencia del proceso y para
recuperar ideas de ornamentación, pero no son arte final ni están conectadas al
juego.

| Archivo | Uso explorado |
|---|---|
| `ornamental-frame.jpg` | Primer marco vegetal cuadrado |
| `ornamental-frame-full.jpg` | Variante posterior con papel y marco completo |
| `ornamental-corner.jpg` | Esquina vegetal para pergamino |
| `tree-seal.jpg` | Sello circular con el árbol del valle |
| `scroll-banner.jpg` | Banda de pergamino para títulos |
| `oak-leaf.jpg` | Hoja de roble ornamental |

La carpeta está separada de `public/ui/art/`: los JPG originales no se sirven
al juego. El 23 sep 2026 se recortaron la hoja y el sello como PNG transparentes
(`ornament-oak-leaf.png` y `ornament-tree-seal.png`) y se integraron en la
bandeja y la decisión. La banderola, la esquina y los dos marcos siguen como
referencias sin integrar.
